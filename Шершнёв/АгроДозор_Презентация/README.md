# АгроДозор — презентация проекта (защита «Студенческий стартап», ВКС Минсельхоз России, 25.11.2026)

Автономная HTML-презентация из 15 сцен: от титульного слайда до «Спасибо за внимание».
Запускается без интернета, собирается в один файл `index.html` + папка `assets/`.

## Запуск

**Рекомендуемый способ (полноценное 3D):**

```bash
cd АгроДозор_Презентация
python3 -m http.server 8099
# открыть http://localhost:8099/ в Chrome / Firefox / Edge
```

Подойдёт любой статический сервер (`npx serve`, расширение Live Server и т. п.).

**Просто открыть `index.html` двойным кликом** — тоже работает, **но** браузер не отдаёт
`assets/3d/model.bin` через `file://` (политика CORS для `fetch`), поэтому интерактивная
3D-модель на сценах 1 и 6 автоматически заменится статичным изображением концепта.
Все 15 сцен, навигация, цикл на сцене 5, заметки и лайтбокс при этом работают полностью.

## Управление

| Действие | Клавиши / элементы |
|---|---|
| Следующая сцена | `→`, `Space`, `PageDown` |
| Предыдущая сцена | `←`, `PageUp` |
| Весь экран | `F` или кнопка «Весь экран» |
| Заметки докладчика | `N` или кнопка «Заметки» |
| Показать сначала | `R` или кнопка «Заново» |
| Закрыть лайтбокс / заметки | `Escape` |
| Сцена 5 (рабочий цикл) | кнопки «Шаг ←/→» и «Проиграть цикл» справа; стрелки `←/→` листают шаги, после последнего шага — переход к следующей сцене |
| Сцена 6 (3D-тур) | кнопки узлов 0–5 слева, вращение — мышью/пальцем, масштаб — колесо |
| Точки-навигация | нижняя панель, 15 точек |

Печать: `Ctrl/Cmd + P` — каждая сцена выводится на отдельную страницу (печать-стили встроены).

## Структура

- `index.html` — вся разметка, стили и логика (без внешних зависимостей).
- `assets/3d/model.bin` + `assets/3d/model.json` — низкополигональная сетка машины, сконвертированная из CAD-модели проекта (FreeCAD, мм, Z-up): 11 групп (`body`, `manipulator`, `tube`, `hopper`, `rubber`, …), ~55 тыс. треугольников, ориентация и масштаб выправляются при загрузке.
- `assets/img/` — изображения (концепт-рендер машины, иллюстрации разметки, фото команды).
- `assets/fonts/` — Montserrat / Manrope / IBM Plex Mono (кириллица + латиница, woff2, 22 файла).
- `assets/three.min.js` — Three.js r140 (MIT, см. `assets/three.min.js.LICENSE`).

## Ограничения и честные оговорки (важно для защиты)

1. **WebGL проверен в headless-Chromium** (программный растеризатор SwiftShader): сцены 1 и 6 рендерятся, орбита и маркеры работают. На машине защиты откройте презентацию в свежем Chrome/Firefox/Edge — в редких случаях (выключенный/запрещённый WebGL) включится статичный fallback, всё остальное работает как обычно.
2. Все характеристики («0,7 га/ч», «6 часов», «3 камеры», «5–100 г» и т. д.) — **проектные/целевые**, испытаниями не подтверждены. Это прямо указано на сценах 3, 7, 11, 12 и 14.
3. Сцена 5 («Один нажим — полная доза под землёй») подписана как **иллюстрация принципа**, а не запись испытаний.
4. Изображение машины на сцене 3 — **концепт-визуализация** (рендер), не фото испытаний.
5. Кадры «YOLO» на сцене 8 — **иллюстрации** машиной разметки, созданные для презентации; оригиналы размеченных кадров — во внутренних материалах проекта. Это не результаты полевых испытаний модели и не доказательство её точности.
6. Уровень готовности: **TRL-проектный образец в разработке**; «обученной модели» в продукте нет, заявка № в материалах конкурса не указан.
7. Интернет не требуется ни на одном этапе показа.
8. Общий объём папки ≈ 6 МБ; внешних запросов (CDN, шрифты, метрики) нет — всё локальное.

## Живая страница (одностраничное кино о проекте)

- `onepage.html` — исходник «живой» версии в стиле immersive-сайтов (одна непрерывная 3D-сцена, колесо мыши листает сцены-акты, как в боржоми): 7 актов — Заявка → Задача → Как это работает (автоплей-шаггер) → Машина → Честно о проекте → Команда → Защита. 3D-модель та же CAD-сетка, камера и подсветка меняются от акта к акту; точка-навигация слева (1–7, стрелки, Home/End, F — весь экран, R — сброс камеры).
- `АгроДозор_Живая_Страница.html` — **та же страница одним самодостаточным файлом** (~6,7 МБ; шрифты, three.js, 3D-модель и изображения встроены base64). Открывается двойным кликом с `file://`, работает без интернета. Собирается из `onepage.html` командой `python3 build_standalone.py`. Проверена в headless-Chromium (SwiftShader): ошибок консоли нет.
- Команда на странице — **только два реальных человека** (Игорь Шершнёв, автор проекта; Екатерина Скакунова, агроном проекта) — **настоящие фотографии** в арх-рамках с янтарной гаммой, без каких-либо сгенерированных лиц. Научного руководителя на странице нет сознательно.
- Изображение «Очаг грызунов» (акт 2) — иллюстрация из материалов проекта; баннер финала — поле в Краснодарском крае, фото. Все характеристики — целевые, испытаниями не подтверждены (акт 5 говорит об этом прямо).
